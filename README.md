# 🛠️ CyberFix-It — Landing Page de Servicio Técnico

Sitio web estático enfocado en alto rendimiento, SEO local y conversión de clientes para un negocio de reparación de equipos informáticos y microelectrónica.

### 🚀 Tecnologías utilizadas
* **Framework:** Astro
* **Estilos:** Tailwind CSS
* **Lenguaje:** TypeScript / JavaScript
* **Despliegue:** Vercel

### ⚡ Características principales
* Diseño ultra minimalista y responsive (Mobile-First).
* Carrusel interactivo optimizado para fotos y videos de reparaciones.
* Integración directa con WhatsApp para cotizaciones rápidas.
* Arquitectura basada en componentes reutilizables.
